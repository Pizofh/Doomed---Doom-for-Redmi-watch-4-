# Playing

Open DOOM II and press START once. Keep the screen awake during CHECKING/LOADING. START opens the title; it does not automatically load your save.

| Control | Action |
|---|---|
| Arrows | Forward, backward and turn |
| FIRE / USAR | Shoot / doors and switches |
| ARMA ?/+ | Cycle available weapons |
| MENU | Original menu; arrows, OK and ATR?S navigate |
| PAUSA ? GUARDAR | Save; wait for GUARDADO |
| PAUSA ? CARGAR ? SEGUIR | Restore; wait for CARGADO before continuing |
| PAUSA ? SALIR | Close; wait for CLOSED before changing faces |

One touch action is active at a time. Sound effects may stutter; music is absent. Top MENU/PAUSA overlays can require precise taps.

In R405, FIRE becomes SIGUE between maps and USAR stays visible. Press and release SIGUE to skip statistics and continue. Physical confirmation of this correction is pending.

Saves use two alternating validated local copies. There is no automatic save on exit. Removing the face can remove its saves and game data; retain the previous version until an upgrade works.

If ERROR appears, record INFO ? GATE/CODE and the preceding steps. Avoid repeatedly reopening a failed session. If the game image remains over system menus, restart normally from Settings; do not factory reset.
