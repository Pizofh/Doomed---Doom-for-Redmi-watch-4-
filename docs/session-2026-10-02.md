# Reporte de primera sesión — 2026-10-02

## Confirmado

Repositorio Git local creado con documentación, 23 hipótesis clasificadas, SHAs upstream fijados y scripts de preparación/inspección. Fuentes consultadas en [research.md](research.md). Xiaomi publica pantalla 390×450/60 Hz y RAM/ROM 32/256 MB. Teardown original identifica BES2700iBP; datasheet BES documenta STAR-MC1 y 2.2 MB SRAM compartida, sin determinar heap libre/ABI RW4.

Existe fuente TouchEvents específica RW4, proyecto 390×450 y binding Lua LVGL con touch. Se leyeron sus fuentes y se descargaron seis archivos originales a una carpeta local ignorada; todos coinciden por hash Git blob. **No se probó ejecución.** ZIP MiWatchEmulator v1.0 recibido del usuario, inspeccionado y extraído selectivamente. Los 94 EXE/DLL del emulador coinciden con OpenVela SHA 3776c05; ADB tiene firma Google válida. La imagen guest contiene macros FLAT/Cortex-A7 y soporte compilado Lua/ELF/módulos/WAMR. [Revisión y hashes](emulator-package-review.md).

EasyFace declara origen del emulador Watch S3. LICENSE de doomgeneric inspeccionada (GPLv2), interface/defaults consultados; sin build ni WAD.

## Refutado / corregido

No es válido inferir réplica M2315W1 de un preset RW4. El flujo de debug físico oficial consultado está limitado a S4/partners; no demuestra soporte RW4. doomgeneric no usa 320×200 por defecto: header 640×400. `get_vect()` del sample no representa posición absoluta. Una variable `/data/tmp.log` no prueba escritura. RAM-only no equivale a sandbox.

Ninguna de estas correcciones refuta el objetivo final de DOOM stock.

## Incógnitas

En RW4: firmware/región, modo de build/privilegios, ISA/ABI efectiva, exports/libc/loader, Lua version, `os.execute`, ELF/`insmod`/WASM, filesystem accesible, framebuffer/input C, memoria libre, launcher persistente y recovery. En emulador: runtime y exposición de las capacidades compiladas, exports/entrypoint y contrato de payload, memoria libre y ciclo de vida UI. Las hipótesis permanecen explícitas en [la matriz](evidence-matrix.md).

Help del launcher y `adb version/help` funcionaron.

## Native execution

Lua/watchface es la superficie específica RW4 mejor sustentada documentalmente. QuickApp/JS/RPK es una API oficial Vela, con compatibilidad RW4 pendiente. ELF/exec, módulos/insmod y WASM/iwasm aparecen compilados en la imagen del emulador. No se ejecutó un payload ni se demostró compatibilidad M2315W1. El emulador FLAT comparte memoria; no describir sus módulos como sandbox.

## Riesgo

No se conectó hardware ni hubo mods, exploits, flash o writes al dispositivo. Se extrajo el emulador, se ejecutaron componentes host revisados y el usuario creó un registro INI en su perfil del PC; no se instaló software con privilegios de administrador. Las pruebas del guest utilizarán una copia de trabajo reversible. Gate físico cerrado; [plan](physical-device-plan.md) declara pendientes de recuperación/compatibilidad y requisitos por acción. Archivos de terceros/WAD/firmware quedan ignorados.
