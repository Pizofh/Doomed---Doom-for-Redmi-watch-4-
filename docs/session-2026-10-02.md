# Reporte de primera sesión — 2026-10-02

## Confirmado

Repositorio Git local creado con documentación, 23 hipótesis clasificadas, SHAs upstream fijados y scripts de preparación/inspección. Fuentes consultadas en [research.md](research.md). Xiaomi publica pantalla 390×450/60 Hz y RAM/ROM 32/256 MB. Teardown original identifica BES2700iBP; datasheet BES documenta STAR-MC1 y 2.2 MB SRAM compartida, sin determinar heap libre/ABI RW4.

Existe fuente TouchEvents específica RW4, proyecto 390×450 y binding Lua LVGL con touch. Se leyeron `main.lua`, `root.lua`, `image.lua` y `.fprj` remotamente. **No se probó ejecución.** Release MiWatchEmulator v1.0 identificada; EasyFace declara origen del emulador Watch S3. LICENSE de doomgeneric inspeccionada (GPLv2), interface/defaults consultados; sin build ni WAD.

## Refutado / corregido

No es válido inferir réplica M2315W1 de un preset RW4. El flujo de debug físico oficial consultado está limitado a S4/partners; no demuestra soporte RW4. doomgeneric no usa 320×200 por defecto: header 640×400. `get_vect()` del sample no representa posición absoluta. Una variable `/data/tmp.log` no prueba escritura. RAM-only no equivale a sandbox.

Ninguna de estas correcciones refuta el objetivo final de DOOM stock.

## Incógnitas

Firmware/región del usuario, modo de build/privilegios, ISA/ABI efectiva, exports/libc/loader, Lua version, `os.execute`, ELF/`insmod`/WASM, filesystem accesible, framebuffer/input C, memoria libre, launcher persistente y recovery. Las hipótesis permanecen explícitas en [la matriz](evidence-matrix.md).

## Emulador

**Bloqueado antes del arranque.** Los cuatro clones fallaron por red de terminal; navegador/conector permitieron consultar fuentes y metadata. El usuario confirmó que no tiene el paquete local y que nunca tocó el reloj. No se descargó ZIP, no se revisaron binarios, no se obtuvo `adb shell`, no se hizo inventario guest y no se ejecutó sample Lua. No se inventaron logs, métricas ni resultados.

Hay plantillas de comandos y una allowlist de inventario en [emulator.md](emulator.md). ZIP v1.0: 733,139,307 bytes, digest publicado ausente. Antes de correrlo, revisión de paquete/launcher/procedencia; si no se verifica origen suficiente, usar alternativa oficial Xiaomi.

## Native execution

Lua/watchface es la superficie específica RW4 mejor sustentada documentalmente. QuickApp/JS/RPK es una API oficial Vela, con compatibilidad RW4 pendiente. Userspace ELF, módulos y WASM siguen sin demostración local o M2315W1. NuttX ofrece mecanismos upstream condicionados por build; no autorizan ejecutar payload nativo.

## Riesgo

No se conectó hardware, no se instaló software, no hubo mods, exploits, firmware o writes a dispositivo. Solo documentación, Git y herramientas del proyecto en PC. Gate físico cerrado; [plan](physical-device-plan.md) declara pendientes de recuperación/compatibilidad y requisitos por acción. Archivos de terceros/WAD/firmware quedan ignorados.
